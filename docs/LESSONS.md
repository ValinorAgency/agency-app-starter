# Proven Project Learnings

Record only learnings supported by project evidence. This document is not a changelog, backlog, scratchpad, automatic memory, or collection of opinions. An observation does not become a rule without sufficient evidence.

## Entry format

### YYYY-MM-DD — Short title

- **Context:** Where and under what conditions the issue occurred.
- **Evidence:** Reproducible observations, results, or references.
- **Learning:** What the evidence supports.
- **Applicability:** Where the learning does and does not apply.
- **Derived action or change:** The concrete response, if any.
